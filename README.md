# Wahala Sorter

A drag-and-drop priority board for daily chaos. Built for builders in Lagos who wake up with a pile of tasks ("wahala") and need a fast, useful tool to sort them into Now, Soon, and Later.

## Mission
Not pretty for the sake of pretty. Useful. Flat design, calm focused colors, and fast interactions. 

## Tech Stack
- React + Vite
- TypeScript
- Vanilla CSS
- `@dnd-kit` for drag and drop interactions

## Getting Started
1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Open `http://localhost:5173` in your browser.
