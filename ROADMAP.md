# Roadmap

What comes after the MVP for Wahala Sorter:

## Phase 1: Persistence
- Save state to `localStorage` so tasks survive page reloads.
- Add an "export" feature to backup the board state as JSON.

## Phase 2: Customization
- Allow users to rename columns.
- Allow adding new columns or removing existing ones.
- Task color coding (e.g., red for high priority).

## Phase 3: Cloud & Collaboration (Optional)
- Integrate a lightweight backend (e.g., Supabase or Firebase).
- Enable real-time syncing across devices.
- Multi-user boards for team collaboration.
